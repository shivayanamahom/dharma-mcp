# Журнал изменений

## 0.3.3 — 2026-10-15
- Исправлено: сервер при `initialize` называл свою версию `0.2.0`; теперь версия берётся из установленного пакета. Версия добавлена в ответ `ping` (`server_version`).

## 0.3.2 — 2026-10-15
- OAuth: адрес ресурса в метаданных теперь совпадает с адресом, которым пользуется клиент (`/mcp` или `/index.php/mcp`); заголовок 401 указывает на метаданные без редиректа Joomla. Это нужно сайтам без перезаписи адресов (nginx).
- Документация: правила nginx для `/mcp`, `/oauth/*` и `/.well-known/*`.

## 0.3.1 — 2026-10-15
- Исправлено: в админке кнопка «Создать» вела на «404 Компонент не найден». Все контроллеры, модели и виды компонента теперь явно знают своё имя (`com_dharma_mcp`).
- Исправлено: подписи сортировки списков и статусов журнала вызовов были не переведены; фильтр статуса журнала не находил записи со статусом «ждёт подтверждения».
- Исправлено: возврат к клиенту OAuth после согласия отправляется заголовками приложения Joomla.
- Добавлено: `dev/web-harness.php` — проверка страниц и действий админки и сайта в консоли.
- Обновления через Joomla: в файле источника обновлений указан `client`.

## 0.3.0 — 2026-10-15
- Первая тестовая версия: ядро, наборы «Магазин», «Материалы и меню», «Шаблон», «Система», OAuth 2.1, системный плагин адресов, источник обновлений.
