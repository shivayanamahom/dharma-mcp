# Правила Claude Code для Dharma MCP

Перед любой работой прочитай [`AGENTS.md`](AGENTS.md) — это основной источник правил, структуры репозитория, ловушек Joomla и регламента выпуска. Если этот файл и `AGENTS.md` расходятся, выполняй `AGENTS.md`.

Коротко: ядро магазина не трогаем; запись — только через штатные модели и службы; новое создаётся черновиком; опасное — с подтверждением; документация обновляется в том же изменении; в отчётах отличай «проверено командой» от «предполагаю».
