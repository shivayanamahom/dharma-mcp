# Dharma MCP

**MCP-сервер для сайта на Joomla 6.** Подключите к нему своего ИИ-ассистента (Claude, ChatGPT, Claude Code, Cursor и другие) — и управляйте сайтом из чата: заказы и товары, страницы и меню, модули, шаблон, настройки. Работает на обычном хостинге: **доступ по SSH не нужен**, всё идёт по HTTPS через сам сайт.

> Версия 0.3.0 — тестовая. Проверена на Joomla 6.2 и PHP 8.4. Не используйте на рабочем сайте без резервной копии.

## Что умеет

Сервер состоит из ядра и наборов инструментов — это отдельные плагины Joomla, их можно включать и выключать независимо.

| Набор | Инструментов | Что даёт | По умолчанию |
|---|---|---|---|
| Ядро | 1 | проверка связи, права токена | всегда |
| **Магазин** (Dharma Shop) | 9 | заказы, смена статуса, товары, цены, остатки | включён, если стоит Dharma Shop |
| **Материалы и меню** | 17 | статьи, категории, меню, модули сайта | включён |
| **Шаблон** | 9 | параметры стиля, файлы шаблона, переопределения, откат | **выключен** |
| **Система** | 12 | настройки, плагины, обновления, кэш, журналы, чтение БД, robots.txt | **выключен** |

Полный список — в [docs/TOOLS.md](docs/TOOLS.md). Примеры запросов к ассистенту: «покажи заказы за сегодня», «что заканчивается на складе», «подними цены на бренд X на 5 %», «сделай страницу „Доставка“ черновиком», «добавь баннер в подвал», «поменяй цвет шапки», «почему сайт медленный — посмотри журнал».

## Как это безопасно

- **Действует от имени пользователя Joomla.** Токен привязан к пользователю и не может больше, чем позволяют его права.
- **Три режима сервера:** только чтение; чтение и черновики (живые изменения — с подтверждением); полный доступ (опасное — всегда с подтверждением).
- **Новое создаётся черновиком**, публикуете вы.
- **Двухэтапное подтверждение:** ассистент сначала получает предпросмотр изменения и одноразовый код, выполняет только после вашего согласия.
- **Журнал всех вызовов**, лимит запросов, ограничение токена по IP, срок действия.
- **Данные покупателей по умолчанию скрыты**, тексты из базы помечаются как данные, а не инструкции.
- Опасные наборы (файлы, настройки, база) выключены, а при включении ограничены: белый список путей, проверка синтаксиса, резервные копии с откатом, чтение базы только в режиме READ ONLY.

Подробно: [docs/SECURITY.md](docs/SECURITY.md).

## Установка

1. Скачайте `pkg_dharma_mcp-<версия>.zip` (собирается командой `./build.sh`, см. [docs/INSTALL.md](docs/INSTALL.md)).
2. Joomla → Система → Установка → Расширения → загрузите файл.
3. Компоненты → Dharma MCP → Токены доступа → создайте токен и сохраните его (показывается один раз, сразу с готовой командой подключения).
4. Подключите клиента: адрес сервера, команды и проверка собраны на странице «Компоненты → Dharma MCP → Подключение».

Claude Desktop, claude.ai и ChatGPT подключаются без токена — через вход в Joomla (OAuth). Claude Code, Cursor и скрипты используют токен. Пошагово: [docs/INSTALL.md](docs/INSTALL.md).
