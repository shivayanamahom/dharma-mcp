**MCP-сервер для сайта на Joomla 6.** Подключите к нему ИИ-ассистента (Claude, ChatGPT, Claude Code, Cursor и другие) и управляйте сайтом из чата: заказы, товары и весь каталог магазина, страницы и меню, модули, шаблон, настройки. Работает на обычном хостинге: **доступ по SSH не нужен**, всё идёт по HTTPS через сам сайт.

> **Версия 0.x — тестовая.** Проверена на Joomla 6.2 и PHP 8.4. Не используйте на рабочем сайте без резервной копии.

> [!IMPORTANT]
> **Для разработчиков и ИИ-агентов (AI Coding Agents):** перед внесением правок обязательно ознакомьтесь с [AGENTS.md](AGENTS.md) — там описаны структура репозитория, жёсткие правила безопасности (запись только через штатные модели, черновики, подтверждение опасного), ловушки Joomla 6 и регламент выпуска. Если ассистент не правит код, а **работает через этот сервер**, ему достаточно инструкций, которые сервер сам отдаёт при подключении (`initialize`), и раздела «Если вы ассистент, подключённый к серверу» в `AGENTS.md`.

## Что умеет

Сервер состоит из ядра и наборов инструментов. Наборы — отдельные плагины Joomla, их можно включать и выключать независимо.

| Набор | Инструментов | Что даёт | По умолчанию |
|---|---|---|---|
| Ядро | 1 | проверка связи и прав токена | всегда |
| **Магазин** ([Dharma Shop](https://github.com/shivayanamahom/dharma-shop)) | 20 | заказы; товары (создать, изменить, удалить, картинки); категории, бренды, бейджи; поля и фильтр; акции и промокоды; доставка и оплата; статусы, склады, покупатели; посадочные страницы; цены, остатки; настройки магазина | включён, если стоит Dharma Shop |
| **Материалы и меню** | 17 | статьи, категории, меню, модули сайта | включён |
| **Шаблон** | 9 | параметры стиля, файлы шаблона, переопределения, откат | **выключен** |
| **Система** | 12 | настройки, плагины, обновления, кэш, журналы, чтение БД, `robots.txt` | **выключен** |

Полный список: [docs/TOOLS.md](docs/TOOLS.md). Примеры запросов к ассистенту: «покажи заказы за сегодня», «что заканчивается на складе», «подними цены на бренд X на 5 %», «создай категорию „Чай“ и добавь туда товар с ценой 450 ₽ и фото по ссылке», «заведи промокод на скидку 10 %», «добавь самовывоз со склада на Ленина», «сделай страницу „Доставка“ черновиком», «добавь баннер в подвал», «поменяй цвет шапки», «почему сайт медленный — посмотри журнал».

## Как это безопасно

- **Действует от имени пользователя Joomla:** токен привязан к пользователю и не может больше, чем позволяют его права.
- **Три режима сервера:** только чтение; чтение и черновики (живые изменения — с подтверждением); полный доступ (опасное — всегда с подтверждением).
- **Новое создаётся черновиком** (товары, категории, акции, способы доставки и т. д.), публикуете вы. Удаление всегда сначала в корзину и только с вашего подтверждения.
- **Двухэтапное подтверждение:** ассистент сначала получает предпросмотр и одноразовый код, выполняет только после вашего согласия.
- **Журнал всех вызовов**, лимит запросов, ограничение токена по IP, срок действия, отзыв одним щелчком.
- **Данные покупателей по умолчанию скрыты**, тексты из базы помечаются как данные, а не инструкции.
- Опасные наборы (файлы, настройки, база) выключены, а при включении ограничены: белый список путей, проверка синтаксиса, резервные копии с откатом, чтение базы только в режиме `READ ONLY`.

Подробно, вместе с остаточными рисками: [docs/SECURITY.md](docs/SECURITY.md).

## Установка

### Вариант 1: Прямая установка по URL (рекомендуется)

Ссылка всегда ведёт на **последний** релиз:

```text
https://github.com/shivayanamahom/dharma-mcp/releases/latest/download/pkg_dharma_mcp.zip
```

1. В админке Joomla: **Система** → **Установка** → **Расширения** → вкладка **«Установить по URL-адресу»**.
2. Вставьте ссылку в поле **«URL пакета установки»**.
3. Нажмите **«Проверить и установить»**.

### Вариант 2: Установка из архива

1. Скачайте `pkg_dharma_mcp-<версия>.zip` со страницы [Releases](https://github.com/shivayanamahom/dharma-mcp/releases).
2. **Система** → **Установка** → **Расширения** → вкладка **«Загрузить файл пакета»**.

### Сборка из исходников

```bash
./build.sh
```

Скрипт проверит синтаксис PHP и соберёт `dist/pkg_dharma_mcp-<версия>.zip`.

### После установки

1. **Компоненты → Dharma MCP → Токены доступа → Создать.** Выберите пользователя и самые необходимые области доступа. Joomla один раз покажет токен вместе с адресом сервера и готовой командой для Claude Code.
2. **Компоненты → Dharma MCP → Подключение.** Здесь адрес сервера, команды для Claude Code, Cursor и других программ, инструкция для Claude Desktop, claude.ai и ChatGPT (они входят через вашу учётную запись Joomla, токен не нужен) и **самопроверка**: отвечает ли адрес и работает ли вход через сайт (OAuth).
3. Наборы «Шаблон» и «Система» включайте осознанно: **Система → Плагины**, группа `dharmamcp`.

Подробно: [docs/INSTALL.md](docs/INSTALL.md), в том числе для хостинга на **nginx** и без перезаписи адресов.

## Обновления через Joomla

Пакет поддерживает нативные обновления Joomla («Система» → «Обновление» → «Расширения»). В манифест `pkg/pkg_dharma_mcp.xml` подключён источник обновлений:

```xml
<updateservers>
    <server type="extension" priority="1" name="Dharma MCP">https://raw.githubusercontent.com/shivayanamahom/dharma-mcp/main/updates/pkg_dharma_mcp.xml</server>
</updateservers>
```

Новая версия появляется в списке обновлений сама; загруженный файл проверяется по контрольной сумме SHA-256.
