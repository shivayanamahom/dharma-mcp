# Dharma Shop MCP Server (`com_dharmashop_mcp`)

Официальный **MCP-сервер (Model Context Protocol)** для интернет-магазина **[Dharma Shop](https://github.com/shivayanamahom/dharma-shop)** на базе **Joomla! 6+ (PHP 8.3+)**.

Компонент позволяет владельцу интернет-магазина (и доверенным сотрудникам) безопасно управлять магазином, получать аналитику, работать с заказами и каталогом прямо из чата со своим ИИ-ассистентом (**Claude Desktop**, **ChatGPT**, **Claude Code**, **Cursor** и др.).

---

## Ключевые возможности

* **Транспорт Streamable HTTP**: работает по стандарту MCP поверх JSON-RPC 2.0 (HTTPS POST), не требует постоянных процессов, WebSocket или Node.js — запускается на стандартном PHP-хостинге.
* **Безопасность и строгий ACL**:
  * Никакого прямого SQL: все операции выполняются исключительно через штатные сервисы ядра магазина (`ShopServices`, `OrderStatusService`, модели каталога) с соблюдением всех валидаций и триггеров.
  * Каждый токен/ключ привязан к конкретному пользователю Joomla и ограничен его правами доступа (ACL).
  * Гранулярные области доступа (`scopes`): чтение заказов, каталог, черновики, запись, аналитика, PII.
* **Защита от Prompt Injection**:
  * Данные от покупателей (комментарии к заказам, отзывы) изолируются в специальную обёртку `user_content` и трактуются только как сырые данные, а не как инструкции ассистенту.
* **Двухэтапное подтверждение опасных операций**:
  * Массовое изменение цен, удаление или отмена заказов требуют предварительного предпросмотра и подтверждения одноразовым кодом.
* **Аудит и журнал**:
  * Полный лог всех вызовов инструментов с параметрами и временем выполнения в админке Joomla.

## Установка

1. Скачайте релизный архив `com_dharmashop_mcp.zip`.
2. В административной панели Joomla перейдите в **Система → Установка → Расширения** и загрузите архив.
3. В меню появится пункт **Dharma Shop MCP**:
   * **Токены доступа**: создание ключей, привязка к пользователям и настройка областей прав.
   * **Журнал вызовов**: мониторинг обращений ИИ-ассистентов.
   * **Настройки**: глобальный режим работы (`read_only` / `drafts` / `full_write`), хранение журнала, маскирование персональных данных.

## Подключение клиентов

Эндпоинт MCP-сервера доступен по адресу:
```
https://ваш-сайт.ru/index.php?option=com_dharmashop_mcp&format=json
```
или по ЧПУ-адресу `/mcp` (при включённом SEF).

Авторизация: HTTP-заголовок `Authorization: Bearer <ваш_токен>`.
