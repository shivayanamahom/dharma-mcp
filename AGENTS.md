# AGENTS.md — руководство для ИИ-ассистентов (Dharma Shop MCP)

Проект **Dharma Shop MCP** (`com_dharmashop_mcp`) — самостоятельный официальный компонент MCP-сервера (Model Context Protocol) для интернет-магазина Dharma Shop на Joomla 6+ (PHP 8.3+).

Пользователь говорит по-русски — **отвечайте по-русски**, документацию и коммиты ведите по-русски.

---

## Главные правила проекта

1. **Полная изоляция от ядра магазина**:
   * Ни при каких обстоятельствах не изменяйте и не перезаписывайте файлы ядра `com_dharmashop` и соседних расширений.
   * `com_dharmashop_mcp` устанавливается независимо и общается с магазином только через публичные PHP-сервисы и контракты (`ShopServices`, `OrderStatusService`, модели каталога).
   * Свои таблицы БД: только с префиксом `#__dharmashop_mcp_*`. Никаких `ALTER TABLE` к таблицам магазина.
2. **100 % нативная Joomla в админке**:
   * Вся административная панель компонента строится только на Form XML (`uitab`, `subform`, `searchtools`, нативный тулбар Joomla 6 и модалки Bootstrap 5).
   * Никакого самописного JS/CSS в админке, кроме крайней необходимости (например, кнопка копирования токена в буфер обмена).
3. **Безопасность вызовов**:
   * Никакого прямого SQL-выполнения запросов от ИИ к базе данных магазина. Любое действие (чтение заказов, смена статуса, обновление цены) проходит через сервисы ядра и проверку прав `$user->authorise()`.
   * Токены хранятся в БД исключительно в виде SHA-256 хэшей. Сырой токен показывается только один раз при создании.
   * Все входящие пользовательские тексты (комментарии к заказам, отзывы) заворачиваются в поле `user_content` для защиты от Prompt Injection.
   * Двухэтапное подтверждение для опасных операций (удаление, массовое изменение цен, отмена заказов).
4. **Документирование изменений**:
   * Каждое функциональное изменение сразу документируется в `docs/` и `docs/ROADMAP.md`.
   * Перед крупными архитектурными шагами согласовывайте решение с пользователем.
5. **Коммиты**:
   * Короткие, осмысленные, на русском языке. Автор: `Dharma <shivayanamahom87@gmail.com>`.

## Структура репозитория

* `com_dharmashop_mcp/` — исходники расширения Joomla:
  * `dharmashop_mcp.xml` — манифест компонента.
  * `admin/` — административная часть (контроллеры, модели, представления, формы, SQL).
  * `site/` — публичная точка входа MCP (Streamable HTTP диспетчер).
* `docs/` — проектная документация:
  * `ARCHITECTURE.md` — архитектура сервисов, схемы таблиц и модель безопасности.
  * `ROADMAP.md` — журнал разработки и этапы M0–M7.
  * `PROTOCOL.md` — спецификация инструментов и JSON-RPC 2.0 контрактов.
* `build.sh` — скрипт сборки установочного zip-пакета `com_dharmashop_mcp.zip`.
