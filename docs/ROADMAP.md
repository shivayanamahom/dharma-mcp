## Проверено только частично

- [~] **Страница согласия OAuth в живой сессии.** Проверены: шаблон (отрисовка, экранирование), перенаправление гостя на вход Joomla, логика выдачи кода и обмена. Не проверено: полный проход «вход → согласие → возврат» в браузере и подключение настоящих клиентов (Claude, ChatGPT) — нужен публичный HTTPS-сайт.
- [~] `system.config_set`: проверены проверки значений и путь «файл конфигурации недоступен для записи»; фактическая запись `configuration.php` на стенде не выполнялась (файл только для чтения).
- [~] Админские страницы (список токенов, форма, журнал, настройки) проверены на уровне моделей и форм в консоли, но не визуально в браузере.
